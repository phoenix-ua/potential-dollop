Рекомендований сценарій уроку

1) Коротке проблемне запитання. 2) «Поняття за хвилину». 3) Три інтерактиви з повторними спробами. 4) Практична робота на обраному сюжеті. 5) Самоперевірка, рефлексія, PDF-звіт.

Для документів перевіряйте, чи редактор підтримує потрібні функції. Уроки № 9 і № 11 — практичні роботи № 2 і № 3, № 14 — практична робота № 4. Урок № 15 — підсумкове оцінювання за групами результатів. Рівні — це різні обсяги підтримки та самостійності, а не автоматичні оцінки.

Оцінювання та здавання

PDF-звіт містить відповіді на інтерактиви, самооцінювання, пояснення рішення й рефлексію. Він не замінює готовий продукт і не виставляє оцінку автоматично. Учень додає до електронного журналу PDF-звіт та документ / код / посилання.

Рекомендується оцінювати за результатами, визначеними КТП: для документів — функціональність, структура, посилання та редагування; для Python — коректність алгоритму, тестування, пояснення й самостійність.

Публікація на GitHub Pages

Створіть репозиторій, завантажте всі файли з архіву до кореня (не окремою вкладеною папкою), відкрийте Settings → Pages → Deploy from a branch → main → /(root). Посилання на курс відкриватиме index.html; усі сім уроків доступні з головної сторінки.

Технічні обмеження: GitHub Pages не зберігає роботи. PDF створюється через системний діалог друку. Python у браузері завантажується з CDN Pyodide, тому для запуску потрібен інтернет. Усі введені учнями дані лишаються в браузері до закриття сторінки; спеціального збереження прогресу немає. Для зручності учень має зберігати код окремо.
